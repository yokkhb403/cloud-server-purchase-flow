## 第二步：地域和可用区怎么定？

地域选离目标用户最近的那个，这是影响访问速度最直接的因素。面向中国大陆用户的网站还要过备案这一关：服务器在大陆地域，域名必须完成 ICP 备案，否则云平台会拦截未备案网站的访问，域名打不开。不想走备案流程，可以选香港地域，没有这个要求。

可用区是地域下面的细分选项，购买页会一并让你选。个人项目和小网站选默认可用区就行；对可用性有要求的业务，可以在同一地域内选不同可用区分散部署。

## 第三步：实例配置和系统镜像怎么选？

CPU、内存、带宽、系统盘按业务负载来定，没有统一答案；系统镜像优先选 Linux 发行版，商业系统要留意授权费。

这一步在页面上是自定义配置：选实例规格、网络、系统盘，再选操作系统镜像。Linux 发行版里 Ubuntu Server、Debian、AlmaLinux、Rocky Linux 都是常见选择。Windows Server、RHEL、SUSE 这类系统可能需要单独付费才能选用，选镜像时留意价格有没有变化。

## 第五步：开通后怎么登录管理？

支付后服务器立即开通，1–5 分钟内能看到 IP 地址，然后通过控制台或 SSH 登录管理。Linux 实例用 SSH 连接，Windows 实例走远程桌面。

## 购买流程里容易踩的三个坑

**先买服务器，再想备案。** 大陆地域的服务器，网站没备案就无法通过域名访问。正确的顺序是先确认备案资格和周期，再下单买服务器。

**没注意系统镜像的授权费。** Linux 发行版大多免费，Windows Server 等商业系统可能产生额外费用。选镜像时看一眼价格变化，别等账单出来才发现。

**计费模式和业务周期对不上。** 长期业务用按量计费、一次性任务买包年包月，都是把钱花在不需要的地方。按量计费和竞价实例按秒计费、小时结算，短任务的实际成本可以很低，没必要用包年包月去跑一次性的活。

## 常见问题

**购买后多久能用？**
支付后立即开通，等待 1–5 分钟即可看到 IP 地址并登录管理。

**支持哪些付款方式？**
余额支付、网银支付、微信支付、QQ 钱包支付。

**大陆的服务器一定要备案吗？**
是。网站架设在大陆地域的服务器上，必须完成 ICP 备案，否则云平台会拦截访问，域名打不开。香港地域的服务器没有备案要求。

**不用控制台能买吗？**
可以。腾讯云提供创建实例的 API 接口，适合习惯编程或需要批量开通的用户。

**包年包月和按量计费哪个更便宜？**
取决于使用时长，没有一刀切的答案。短期任务用按量计费更灵活，长期稳定运行用包年包月一次性付清；两种模式的价格都随配置变化，以购买页显示为准。
